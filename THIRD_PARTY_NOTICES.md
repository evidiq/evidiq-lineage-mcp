# Third-Party Notices

EVIDIQ Lineage is original EVIDIQ integration code. It consumes pinned packages without copying or relabeling their source. Lineage does not remove any license, notice, copyright, or README material that an installed package actually ships. Some npm artifacts expose their license only through SPDX metadata in `package.json` and do not include a standalone license file; this consolidated notice therefore records the exact direct-package metadata and upstream location. Source distributions and container images must retain this notice, package manifests, and every upstream license/notice file that is available.
